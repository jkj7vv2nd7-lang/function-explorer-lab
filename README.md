# 関数探究ラボ

小学校・中学校・高等学校で学ぶ関数を、グラフを動かしながら探究する Windows 11 用の学習ソフトです。先生は授業の準備に使えます。生徒は「予想する → 操作して確かめる → 説明する」の順に学べます。

> **ダウンロード**：ページ右側の **Releases**（リリース）から、最新の `FunctionExplorer-Lab-Windows11-x64.exe` をダウンロードしてください。詳しい手順は [操作マニュアル](MANUAL.md) にあります。

## このソフトでできること

- 比例・反比例・一次関数・二次関数・指数関数・対数関数・三角関数のグラフを表示する
- 係数を変えて、式・表・グラフの変化を比べる
- グラフ上の点の座標や、2点間の平均変化率を調べる
- x と y の対応表を表示し、x の値を変えて確かめる
- グラフから切片、頂点、対称軸、周期などの特徴を読み取る
- 生徒モード、全画面提示、授業タイマーを使って授業を進める
- 授業案のひな型を使い、問い・予想・観察・説明を準備する
- 教材を保存、複製、印刷し、パッケージにして受け渡す
- 生徒の探究記録を複数まとめて読み、学年・単元ごとの自己評価を集計する
- 教師コメントを記録し、CSV に出力する
- 集計を手がかりに、次の授業の活動案を作る

## まず使ってみよう

1. Releases から EXE をダウンロードします。
2. ダウンロードした `FunctionExplorer-Lab-Windows11-x64.exe` をダブルクリックします。
3. 学年と関数を選び、場面教材を選びます。
4. グラフの形を見て、動かせる係数があればスライダーを動かします。
5. 表やグラフからわかったことを、生徒モードの記録欄に書きます。

## 子どもたちの学び方

### 1. 予想する
「係数を大きくしたら、グラフはどうなるかな？」など、操作する前に自分の考えを書きます。

### 2. 操作して確かめる
係数を変えたり、グラフをクリックして座標を調べたり、対応表を開いたりします。予想と同じだったか、違ったかを記録します。

### 3. 説明する
式・表・グラフから見つけた数値や形を根拠にして、「なぜそう考えたか」を説明します。最後に自分で振り返ります。

## Windows 11 での動作

- Windows 11、64 ビット PC 向けです。
- 配布 EXE は .NET ランタイムを含む単体形式です。別途 .NET をインストールしなくても起動できます。
- 学習時にインターネット接続は必要ありません。
- Windows の警告が出た場合、発行元未確認のアプリであることを示している可能性があります。学校・家庭の管理者に確認してから実行してください。

## 記録とプライバシー

- 授業で作った教材や生徒の記録は、保存先を選んで PC 内に保存します。
- アプリは生徒の記録を自動で GitHub やインターネットへ送信しません。
- 生徒記録には、書いた予想・観察・説明・振り返りが含まれます。共有する前に、氏名・学校名・住所などを書かないようにしてください。
- 教師コメントは、生徒記録とは別の `.teacher.json` ファイルに保存されます。記録とコメントを一緒に移動・保管してください。
- GitHub の公開リポジトリに、実際の生徒の記録や個人情報を登録しないでください。

## 対応する学習内容について

収録内容は、関数を探究するための学習支援です。学校で使用する教科書や授業計画に合わせ、先生が問い・範囲・教材を調整してください。すべての教科書の問題や単元を収録しているわけではありません。
